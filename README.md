# Database Design and Implementation

My university group project for the Database Design and Implementation course (COMP11109).

## About this project

This is coursework from my MSc Information Technology at the University of the West of Scotland. It is a group project by five students.

We designed a database for an appointment scheduling system for a small service business. The idea was to move the business from paper records to a digital system.

The report covers the full process:
- Conceptual design with ER diagrams
- Normalization to third normal form (3NF)
- Building the tables in Microsoft Access, with relationships and validation rules
- Filling the database with sample data
- Writing and testing 10 SQL queries
- Designing forms and reports for the user interface
- Privacy and security notes, including GDPR
- A reflection on what we learned

The database has seven tables: Client, Employee, Service, ClientAppointments, ServicesProvided, Invoice, and InvoiceRows.

My part in the project was the SQL queries, the screenshots, and report writing.
